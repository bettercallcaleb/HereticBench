# HereticBench v1.0.0 — Release Notes

v1.0.0 freezes the first public HereticBench protocol.

## Included axes

- Boundary / refusal / RSAR
- Calibrated capability retention and instruction integrity
- 100-prompt blind OpenBehavior
- 120-case Epistemic Integrity

## Reference-study headline

- Base harmful RSAR: 100% at low/medium/xhigh
- Heretic harmful RSAR: 0% at low/medium/xhigh
- Capability signal: 71.7% Base vs 81.7% Heretic
- OpenBehavior: 94 ties in 100 blind pairs; no 3/4 or 4/4 divergence
- Epistemic: 100% vs 97.5% strict; 100% vs 100% functional

## Important release decisions

- No unified score.
- Saturated retention families are kept as diagnostics, not headline capability evidence.
- Raw harmful completions are not bundled.
- Quantization mismatch is prominently disclosed.
- v1.0 is frozen; new tracks belong in later versions.
