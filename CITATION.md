# Citation

If you use HereticBench, cite the repository/version you actually ran. A generic BibTeX template:

```bibtex
@misc{hereticbench2026,
  title        = {HereticBench: Measuring Behavioral Change Beyond Refusal},
  author       = {{HereticBench contributors}},
  year         = {2026},
  howpublished = {Open-source benchmark},
  note         = {Version 1.0.0}
}
```

Replace the repository URL and author metadata with the public release metadata if you publish under a personal or organizational name.
