# Contributing

Useful contributions include:

- matched Base/Heretic replications
- additional model families
- independent blind OpenBehavior judgments
- improved refusal/RSAR classifiers with audited false-positive/false-negative examples
- new retention families that avoid both ceiling effects and token-exhaustion traps

Please report results as separate axes. Do not submit a single composite "HereticBench score" without the underlying axis metrics.

Do not include raw operationally harmful model completions in issues or pull requests. Aggregate statistics, classifiers, prompts, and sanitized failure descriptions are sufficient for benchmark development.
